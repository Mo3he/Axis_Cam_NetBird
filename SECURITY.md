# Security Policy

This is an independent, community-developed ACAP package. It is not an official
Axis Communications product and is provided on a best-effort basis.

## Reporting a vulnerability

Please report security issues privately through GitHub Security Advisories or by
emailing <moshe@mohome.net>. Include the affected version, camera model and
AXIS OS version, impact, and reproduction steps. Do not publish credentials or
setup keys in an issue.

## Scope

The ACAP bridge, configuration handling, web UI, proxy binding, and packaging
are in scope. Vulnerabilities in NetBird, WireGuard, gVisor, Go, or other bundled
upstream components should also be reported to their respective projects.
